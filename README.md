# Arduino LED Blinking – QA Documentation

## 1. Project Overview

This project demonstrates a basic embedded system using an Arduino
board and an LED. The objective is to blink an LED at a fixed interval
and document the quality assurance and problem-solving process using GitHub.

## 2. Hardware Used

- Arduino Uno
- LED
- 220Ω resistor
- Breadboard
- Jumper wires

## 3. Software Used

- Arduino IDE
- Arduino C/C++
- GitHub

## 4. Working Principle

The Arduino configures the LED pin as an output. The LED is switched ON
for one second and OFF for one second repeatedly.

## 5. Expected Behaviour

The LED should:

1. Turn ON.
2. Remain ON for approximately 1 second.
3. Turn OFF.
4. Remain OFF for approximately 1 second.
5. Repeat continuously.

## 6. QA Process

GitHub Issues were used to document identified problems, their severity,
root causes and proposed solutions.

The issues were discussed through GitHub comments and resolved through
code modifications and commits.

## 7. Project Tracking

GitHub was used for:

- Source-code management
- Issue tracking
- QA documentation
- Comments and collaboration
- Commit history
- Problem resolution
